User Behaviour & Funnel Analysis

A web-analytics case study showing how event data can be structured into a conversion funnel, analysed by journey stage, and translated into actionable product and marketing questions.

GA4GTMSQLClarityFunnel Analysis

Business question

Where do users enter the journey, where do they drop off, and which parts of the digital experience deserve further investigation? The analysis connects acquisition, engagement, registration, and application events into a consistent funnel.

Analytics approach

Event taxonomy

Standardise page views, button interactions, registration events, UTM dimensions, and funnel events so analysis is consistent.

Journey analysis

Compare user counts and conversion between stages rather than looking at individual events in isolation.

Segmentation

Break down performance by acquisition source, page, device, period, and other useful dimensions.

Behaviour validation

Use session recordings or heatmaps as supporting evidence when a quantitative funnel indicates a potential UX issue.

Example SQL

SELECT
    event_date,
    event_name,
    COUNT(DISTINCT user_id) AS users
FROM ga4_events
WHERE event_name IN (
    'page_view',
    'registration',
    'application_start',
    'application_complete'
)
GROUP BY event_date, event_name
ORDER BY event_date;

The code is a portfolio example. It does not expose proprietary event data or internal company identifiers.

What this demonstrates

This case study demonstrates the analytical workflow: define a measurable journey, ensure tracking is consistent, transform event data into useful metrics, investigate drop-off, and communicate findings through dashboards and reporting.
