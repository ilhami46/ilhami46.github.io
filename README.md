# Aiman Ilhami — Data Analytics Portfolio

Personal portfolio website for **Aiman Ilhami**, Data Analyst & Reporting.

🌐 **Live portfolio:** https://ilhami46.github.io/

## About

This portfolio showcases selected work across:

- Business intelligence and management reporting
- SQL and data analysis
- GA4 and web analytics
- BigQuery analytics pipelines
- Data quality and validation
- Power Automate workflow automation
- Data visualisation

Company-specific information is represented with anonymised or synthetic examples where appropriate.

## Selected case studies

| Project | Focus | Technologies |
|---|---|---|
| Fintech Analytics & Reporting | BI, KPI reporting, dashboards | QuickSight, Power BI, SQL, Excel |
| GA4 → BigQuery Analytics | Analytics engineering, reconciliation | GA4, BigQuery, SQL, Python |
| User Behaviour & Funnel Analysis | Web analytics and conversion analysis | GA4, GTM, Clarity, SQL |
| Management Approval Workflow | Process automation | Power Automate, Forms, PDF |
| Registration & Data Quality | Duplicate-account and verification analysis | SQL, Python |

## Tech stack

- **Languages:** SQL, Python, R, HTML, JavaScript
- **BI:** Amazon QuickSight, Power BI, Looker Studio, Excel
- **Analytics:** Google Analytics 4, Google Tag Manager, Microsoft Clarity
- **Data:** BigQuery, SQL-based transformation and validation
- **Automation:** Microsoft Power Automate
- **Delivery:** Jira, Git, GitHub Pages
