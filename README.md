# Aiman Ilhami — Data Analytics Portfolio

Personal portfolio website for Aiman Ilhami, Data Analyst & Reporting.

## Stack
- HTML5
- CSS3
- Vanilla JavaScript
- GitHub Pages

## Local preview
Open `index.html` in a browser, or use a local static server.

## GitHub Pages
1. Create a GitHub repository named `aiman-portfolio` (or another preferred name).
2. Upload/push the project files.
3. In GitHub: Settings → Pages.
4. Select **Deploy from a branch**, choose `main` and `/root`.
5. Save and wait for the deployment.

The portfolio is designed to use anonymised/synthetic data for confidential company projects.
